# Image assets

Drop your images into the right subfolder and they'll show up automatically.

| Where | What | File path expected |
| --- | --- | --- |
| Hero portrait | A photo of you (4:5 portrait works best) | `public/images/hero/portrait.jpg` |
| About section | Friendly photo / illustration (square) | `public/images/about/about.jpg` |
| Project: ODDESY | Screenshot or mockup (16:10) | `public/images/projects/oddesy.jpg` |
| Project: VNDP | Screenshot or mockup (16:10) | `public/images/projects/vndp.jpg` |
| Project: StudyLah | Screenshot or mockup (16:10) | `public/images/projects/studylah.jpg` |

Need more projects? Add them in `app/data/resumeData.ts` and reference an image
path here using the same convention.

If a file is missing, the UI shows a gentle placeholder — nothing breaks.
